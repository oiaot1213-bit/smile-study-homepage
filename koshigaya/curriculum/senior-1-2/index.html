高校1年生・高校2年生講座

定期テストと大学受験を、別々にしない。

高校・大学受験コース

高校1年生・高校2年生は、「まだ受験生ではない」と考えられやすい時期です。

しかし実際には、大学受験に向けた準備はすでに始まっています。

学校推薦型選抜や総合型選抜では、高校1年生からの評定が重要になります。一般選抜でも、高校3年生になってから高校3年間の英語・数学をすべてやり直すのは簡単ではありません。

一方で、高校は中学校以上に学校ごとの差が大きく、使用教材、授業進度、定期テストの難易度、単元テストの回数も異なります。部活動が忙しく、毎週同じ曜日に通うことが難しい生徒様もいます。

そのため、高校1・2年生講座では、学校の成績を安定させながら、英検や大学受験の準備を少しずつ進めます。

なぜ高校1・2年生を一つの講座にするのか

この時期は、進路を一つに決め切る前に、将来の選択肢を減らさないための準備を行う期間だからです。

高校1年生では、学校の授業に適応し、評定を安定させることが中心になります。高校2年生では、文系・理系、一般選抜・推薦、受験科目などを具体化し、大学受験に使う科目へ比重を移していきます。

両学年に共通するのは、学校の勉強と受験勉強を切り離さず、現在の課題と将来の目標をつなげることです。

実際の授業内容

学校教材を使った定期テスト対策

高校生の定期テストでは、学校指定の問題集やプリントから出題されることが多いため、スマイルスタディでは学校教材を丁寧に確認します。

  • 数学の4STEP、サクシード、チャート系教材
  • 化学・物理のセンサー、セミナー系教材
  • 英語コミュニケーションの教科書本文
  • 論理・表現の学校ワーク
  • 学校配布プリント
  • 前回の定期テスト問題と答案

実際の面談では、学校の平均点や出題傾向、ご本人の答案まで確認し、「数学と化学はテスト前に集中」「英語は通常授業で継続」など、科目ごとの受講方法も調整しています。

英検対策

英検は、単なる資格取得ではなく、大学受験の選択肢を増やす手段として位置づけます。

  • 高校1年生で準2級
  • 高校2年生で2級
  • 志望校や現在の英語力によっては準1級

など、状況に応じて目標を設定します。

過去問を時間を計って解き、結果をもとに、

  • 単語・熟語
  • 文法
  • 長文読解
  • リスニング
  • ライティング
  • スピーキング

のどこへ授業時間を配分するかを決定します。学校の英語と英検対策を完全に分けず、共通する文法・語彙を活かしながら進めるのも特徴です。

大学受験の基礎づくり

高校2年生からは、志望校や受験科目を確認し、必要な科目を絞ります。

理系であれば数学・英語・化学などを継続して積み上げ、文系であれば英語を中心に、現代文・古文・社会を計画的に進めます。

すべての科目を同じ比重で学ぶのではなく、

  • 受験で使う科目
  • 評定を守る科目
  • 学校で赤点を避ける科目
  • 自習で進められる科目
  • 授業で重点的に扱う科目

を分けて考えます。

80分授業の一例

  1. 1学校進度・テスト・課題状況の確認10分
  2. 2前回内容の確認テスト10分
  3. 3学校教材または受験教材の解説25分
  4. 4類題・定期テスト形式の演習25分
  5. 5理解度の言語化・学習計画の調整10分

ここでご紹介しているのは、講座の基本的な考え方です。実際の授業内容は、面談で目標や現在地、学校生活の様子を伺ったうえで、一人ひとりに合わせて決めていきます。
